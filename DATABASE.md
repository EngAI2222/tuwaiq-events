# DATABASE SCHEMA

## Overview
The database is designed to handle user authentication, event booking, AI-generated plans, and platform management. It is designed for PostgreSQL (via Supabase).

## Core Tables

### 1. `users` & `profiles`
- **users:** Managed by Supabase Auth (or NextAuth). Contains email, password, role (`ADMIN`, `STAFF`, `CUSTOMER`).
- **profiles:** Extended user data (Name, Phone, Avatar, Preferences).

### 2. `services` & `categories`
- **categories:** e.g., "Weddings", "Corporate", "Decorations".
- **services:** Specific services under categories (Title, Description, Image, Price From, Features JSON).

### 3. `packages` & `package_items`
- **packages:** Bundled services (e.g., "Luxury Wedding Package").
- **package_items:** Mapping table connecting packages to specific services.

### 4. `events` & `bookings`
- **events:** General event types the system supports.
- **bookings:** Core transactional table. Contains (Customer ID, Event Type, Date, Time, City, Venue, Guests, Budget, Status, Unique Order ID).
- **booking_items:** Services selected for a specific booking.

### 5. `quotes` & `quote_items`
- Custom pricing requested by users or generated by AI.

### 6. `ai_requests` & `ai_plans`
- **ai_requests:** Log of user inputs to the AI Event Planner (Context, Budget, Theme, Guests).
- **ai_plans:** The generated JSON plan provided by the AI, linked to a specific user and request.

### 7. Content & Management
- **gallery:** Portfolio images (URL, Category, Tags).
- **blog_posts:** Content marketing and SEO articles.
- **testimonials:** User reviews.
- **messages:** Contact form submissions.
- **notifications:** System notifications for users.
- **settings:** Global app settings (Hero text, Contact info).
